# 🚀 ALT Linux Sysadmin DE Modules v2.0

**ALT Linux Sysadmin DE Modules** — это мощное stealth-расширение (Manifest V3) для браузеров на базе Chromium. Создано для быстрого доступа к инструкциям и **незаметного, автоматизированного ввода конфигураций в консолях Proxmox (noVNC / xterm.js)** при сдаче Демонстрационного экзамена (ДЭ) по системному администрированию (КОД 09.02.06).

## 🔥 Главные особенности Release 2.0

* **🧩 Модульная архитектура:** Код разделен на независимые логические слои (`state.js`, `keyboard.js`, `parser.js`, `ui.js`, `content.js`), что делает работу расширения молниеносной и безотказной.
* **🧠 Умный поиск (Smart Fetch):** Больше не нужно вручную переключать модули! Просто кликните по имени ВМ в дереве Proxmox (например, `101 (isp)`), и расширение **само найдет** нужный код во всех файлах/фазах, автоматически переключит интерфейс и подсветит рамку нужным цветом. Защищено от случайных кликов по интерфейсу ExtJS.
* **🎯 Keysym Injection (Бронебойный ввод):** Физическая раскладка клавиатуры больше не имеет значения. Спецсимволы (вроде `|`, `>`, `{`) отправляются напрямую в noVNC как чистые коды. Никаких случайных слэшей вместо пайпов!
* **📋 Динамический парсинг КОД (Alt + 3):** Скопируйте текст из PDF-файла с заданием, и расширение автоматически вытянет не только пароли и домены, но и **UID, уровни RAID, VLAN ID и подсети**.
* **🛡️ Безопасная автоматизация:** Шаблоны переведены на использование Here-Doc (`cat <<EOF`) и потокового ввода (`sed`, `echo`), что исключает залипание в интерактивных текстовых редакторах при медленном интернет-соединении на площадке.

## 🎮 Горячие клавиши и Управление

Системные хоткеи имеют наивысший приоритет, сбрасывают любые зависания и работают всегда.

| Комбинация / Кнопка | Действие | Индикация (рамка) |
| :--- | :--- | :--- |
| `Alt` + `1` / `Alt` + `2` | Принудительный выбор активного модуля (1 или 2) | ⬜/⬛ Серая |
| `Alt` + `3` | **Smart Paste:** парсинг вводных данных из буфера обмена (PDF КОД) | 🟩 Зеленая |
| `Alt` + `4` | **Авто-IP:** генерация уникальных "серых" подсетей | 🟦 Синяя |
| `Alt` + `5` | **Сброс:** откат к дефолтной конфигурации параметров | 🟧 Оранжевая |
| `Alt` + `6` | **Режим Хакера:** Старт / Продолжить печать из «Призрачного буфера» | 🟪 Фиолетовая |
| `Alt` + `7` | **Смена Фазы:** Переключение между Фазой 1 и Фазой 2 | ⬜ Белая |
| `Ctrl`+`Shift`+`0` или `Esc` | **Кнопка Паники:** Моментально скрыть интерфейс расширения | — |

## 🪄 Макросы управления редакторами
Если вам все же нужно открыть текстовый редактор, используйте служебные команды прямо в `.md` файлах (расширение само нажмет нужные кнопки):
* `{{EXIT_MCEDIT}}` — авто-сохранение и выход из `mcedit`.
* `{{EXIT_NANO}}` — авто-сохранение и выход из `nano`.
* `{{EXIT_VIM}}` — авто-сохранение и выход из `vim`.
* `{{MC_DEL_LINE}}` / `{{NANO_DEL_LINE}}` — удаление текущей строки.
* `{{DOWN}}`, `{{TAB}}` — навигация.

## 🛠️ Установка на площадке

1. Скачайте/склонируйте репозиторий на локальную машину.
2. Откройте браузер и перейдите по адресу `chrome://extensions/` (или `edge://extensions/`).
3. Включите **«Режим разработчика»** (Developer mode) в правом верхнем углу.
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку с исходным кодом.
5. Зайдите в интерфейс Proxmox. Кликните по любой машине (например, `ISP`).
6. Откройте консоль (noVNC), переведите фокус в черное окно и нажмите `Alt + 6`.
