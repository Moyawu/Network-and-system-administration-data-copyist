# 🚀 Network and System Administration Data Copyist

**ALT Linux Sysadmin DE Modules** — это расширение (Manifest V3), созданное для быстрого доступа к инструкциям и скриптам прямо на страницах wiki ALT Linux с акцентом на максимальную скрытность и безопасность.

## ✨ Главные фичи v1.4 (Stealth Headings Update)

* **🥷 Фантомный код:** По умолчанию блоки с кодом полностью скрыты. Модуль выглядит как обычный текстовый конспект с заголовками.
* **🖱️ Магия заголовков (Интерактивность):**
  * **Левый клик (ЛКМ)** по заголовку — незаметно копирует скрытый под ним код в буфер обмена (заголовок на долю секунды мигнет зеленым).
  * **Правый клик (ПКМ)** по заголовку — плавно показывает/скрывает блок с кодом, если нужно прочитать текст глазками (дефолтное меню браузера при этом заблокировано).
* **👁️ Улучшенная типографика:** Код стал компактным, но легко читаемым. Длинные скрипты аккуратно скроллятся внутри своего блока, не растягивая страницу.
* **🛡️ Kill-switch (Самоуничтожение):** Тройное нажатие `Esc` полностью выпиливает расширение со страницы (скрипты, стили и обработчики событий), не оставляя следов до следующего обновления страницы.
* **👀 Слежка за фокусом и курсором:** Модули автоматически скрываются при смене вкладки, сворачивании окна (`Alt+Tab`) или уводе курсора мыши в верхние 10 пикселей экрана.
* **⚙️ Интерактивная конфигурация:** IP-адреса и домены можно менять прямо в интерфейсе расширения (таблица сверху) перед копированием команд.

## 🎮 Горячие клавиши

| Комбинация | Действие |
| :--- | :--- |
| `Alt` + `1` | Показать / Скрыть **Модуль 1** (Сеть, ISP, RTR) |
| `Alt` + `2` | Показать / Скрыть **Модуль 2** (RAID, NFS, Samba, Docker) |
| `Escape` (1 раз) | **Panic Button:** Моментально скрыть открытые модули |
| `Escape` (3 раза) | **Kill-switch:** Полное удаление расширения со страницы |
| `Ctrl` + `Shift` + `0` | Дополнительная паник-кнопка скрытия |

## 🛠️ Установка

1. Перейдите в `chrome://extensions/`.
2. Включите **«Режим разработчика»** в правом верхнем углу.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку проекта.
4. (Для обновления) После внесения изменений в `.md` файлы или код — нажмите кнопку **«Обновить»** (круговая стрелка) на карточке расширения.

## 📂 Структура проекта
* `manifest.json` — настройки и права расширения (версия 1.4).
* `content.js` — ядро: логика стелс-режима, фантомного кода, хоткеев и инъекции стилей.
* `marked.min.js` — парсер Markdown.
* `modul_1.md` / `modul_2.md` — файлы с шаблонами конфигураций и инструкциями.
