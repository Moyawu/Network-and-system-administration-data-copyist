# 🚀 Network and System Administration Data Copyist



**ALT Linux Sysadmin DE Modules** — это браузерное расширение (Manifest V3), созданное для быстрого и незаметного доступа к инструкциям, шпаргалкам и скриптам прямо на страницах wiki ALT Linux. 



Расширение внедряет Markdown-модули в конец страницы и позволяет моментально копировать нужные команды в один клик. Идеально подходит для системных администраторов и подготовки к ДЭ (демонстрационному экзамену).



## ✨ Главные фичи



***🥷 Скрытый режим (Stealth Mode):** Блоки с кодом полностью скрыты по умолчанию. При активации они плавно появляются и стилистически сливаются с оригинальной разметкой ALT Linux Wiki.

***⌨️ Управление горячими клавишами:** Мгновенный доступ к нужной информации без использования мыши.

***📋 Умное копирование:** Всплывающие кнопки «Копировать» у каждого блока кода, которые появляются только при наведении.

***⚡ Markdown под капотом:** Текст рендерится "на лету" из удобных `.md` файлов с помощью легковесной библиотеки `marked.js`.

## 🎮 Горячие клавиши

Управление шпаргалками происходит максимально быстро:

| Комбинация | Действие |
| :--- | :--- |
| `Alt` + `1` | Показать / Скрыть **Модуль 1** (Базовая сеть, маршрутизаторы, DNS) |
| `Alt` + `2` | Показать / Скрыть **Модуль 2** (RAID, NFS, Samba DC, Nginx, Docker) |
| `Escape` | 🚨 **Panic Button:** Моментально скрыть все открытые модули |

> *Примечание: При открытии модуля страница автоматически плавно прокручивается к его началу.*

## 🛠️ Установка (для разработчиков)

Так как расширение локальное, оно устанавливается в браузер в режиме разработчика:

1. Склонируйте этот репозиторий или скачайте его ZIP-архивом:
	;```bash
	;  git clone [https://gitlab.com/ВАШ_ЛОГИН/network-and-system-administration-data-copyist.git](https://gitlab.com/ВАШ_ЛОГИН/network-and-system-administration-data-copyist.git)
	;```

2. Откройте ваш браузер (Chrome, Яндекс.Браузер, Edge) и перейдите на страницу расширений: `chrome://extensions/`.

3. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).

4. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked) в левом верхнем углу.

5. Выберите папку, в которой находится файл `manifest.json`.

6. Готово! Перейдите на любую страницу `www.altlinux.org/Sysadmin*` и нажмите `Alt+1`.



## 📂 Структура проекта

* `manifest.json` — конфигурация расширения.
* `content.js` — основная логика (загрузка файлов, рендеринг кнопок копирования, обработка хоткеев).
* `marked.min.js` — библиотека для парсинга Markdown в HTML.
* `modul_1.md` / `modul_2.md` — исходные файлы с вашими шпаргалками. Вы можете легко редактировать их в любом текстовом редакторе!

## 📝 Как добавить свои команды?

Просто откройте файлы `modul_1.md` или `modul_2.md` и впишите нужный текст, используя стандартную Markdown-разметку. Блоки кода оборачивайте в тройные обратные кавычки:

```bash
ваш код
```

Расширение автоматически подхватит изменения при обновлении страницы в браузере.
