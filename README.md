# 🚀 Network and System Administration Data Copyist

**ALT Linux Sysadmin DE Modules** — это расширение (Manifest V3), созданное для быстрого доступа к инструкциям и скриптам прямо на страницах wiki ALT Linux. 

## ✨ Главные фичи

* **🥷 Paranoia Mode (Стелс-режим):** Блоки с кодом полностью сливаются с дизайном Wiki. При переключении вкладки или сворачивании браузера (`Alt+Tab`) все шпаргалки моментально скрываются сами.
* **⌨️ Управление хоткеями:** Мгновенный вызов нужного модуля и «паническая кнопка» `Esc`.
* **📋 Скрытое копирование:** Кнопок больше нет. Просто кликните левой кнопкой мыши по любому серому блоку кода, и он моментально окажется в буфере обмена. Блок мягко мигнет зеленым, подтверждая успех.

## 🎮 Горячие клавиши

| Комбинация | Действие |
| :--- | :--- |
| `Alt` + `1` | Показать / Скрыть **Модуль 1** (Сеть, ISP, RTR) |
| `Alt` + `2` | Показать / Скрыть **Модуль 2** (RAID, NFS, Samba, Docker) |
| `Escape` | 🚨 **Panic Button:** Моментально скрыть всё |

## 🛠️ Установка

1. Перейдите в `chrome://extensions/`.
2. Включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку проекта.
4. После внесения изменений в `.md` файлы или код — нажмите кнопку **«Обновить»** (круговая стрелка) на карточке расширения.

## 📂 Структура проекта
* `manifest.json` (v1.2) — настройки расширения.
* `content.js` — логика стелс-копирования и хоткеев.
* `modul_1.md` / `modul_2.md` — ваши данные.
