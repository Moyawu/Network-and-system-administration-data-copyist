# ALT Linux Sysadmin DE Modules v2.1

**ALT Linux Sysadmin DE Modules** — специализированное расширение для браузеров на базе Chromium (Manifest V3), предназначенное для автоматизации и упрощения работы системного администратора во время проведения Демонстрационного экзамена (ДЭ) по компетенции "Сетевое и системное администрирование" (КОД 09.02.06).

## 🚀 Возможности
* **Stealth Integration:** Работает "поверх" консолей noVNC/xterm.js в Proxmox, оставаясь незаметным для интерфейса ExtJS.
* **Smart Parsing:** Автоматический разбор заданий из markdown-файлов (`modul_1.md`, `modul_2.md`).
* **Keysym Injection:** Гарантированный ввод спецсимволов (`|`, `>`, `{`, `}`), минуя проблемы с раскладкой клавиатуры в консоли.
* **Panic Mode:** Мгновенное скрытие интерфейса расширения по горячим клавишам.
* **Dynamic Configuration:** Управление сетевыми параметрами (IP, шлюзы, пользователи) через удобную таблицу конфигураций.

## 📁 Структура проекта
* `content.js` — основная логика внедрения в DOM и обработка событий.
* `keyboard.js` — реализация "бронебойного" ввода символов в консоль.
* `parser.js` — парсер markdown-шаблонов для автоматического ввода команд.
* `state.js` — управление состоянием и настройками конфигурации (`netConfig`).
* `ui.js` — отрисовка интерфейса и функции подсветки элементов.
* `modul_1.md` / `modul_2.md` — шаблоны выполнения заданий для 1-го и 2-го модулей соответственно.

## 🛠 Установка
1. Скачайте репозиторий.
2. Откройте `chrome://extensions/` в браузере.
3. Включите **"Режим разработчика" (Developer mode)**.
4. Нажмите **"Загрузить распакованное расширение" (Load unpacked)** и выберите папку с проектом.

## ⌨️ Управление

Системные хоткеи имеют наивысший приоритет, сбрасывают любые зависания и работают всегда.

| Комбинация / Кнопка | Действие | Индикация (рамка) |
| :--- | :--- | :--- |
| `Alt` + `1` / `Alt` + `2` | Принудительный выбор активного модуля (1 или 2) | ⬜/⬛ Серая |
| `Alt` + `3` | **Smart Paste:** парсинг вводных данных из буфера обмена (PDF КОД) | 🟩 Зеленая |
| `Alt` + `4` | **Авто-IP:** генерация уникальных "серых" подсетей | 🟦 Синяя |
| `Alt` + `5` | **Сброс:** откат к дефолтной конфигурации параметров | 🟧 Оранжевая |
| `Alt` + `6` | **Режим Хакера:** Старт / Продолжить печать из «Призрачного буфера» | 🟪 Фиолетовая |
| `Alt` + `7` | **Смена Фазы:** Переключение между Фазой 1 и Фазой 2 | ⬜ Белая |
| `Ctrl`+`Shift`+`0` или `Esc` | **Кнопка Паники:** Моментально скрыть интерфейс расширения | — |

## 🪄 Макросы управления редакторами
Если вам все же нужно открыть текстовый редактор, используйте служебные команды прямо в `.md` файлах (расширение само нажмет нужные кнопки):
* `{{EXIT_MCEDIT}}` — авто-сохранение и выход из `mcedit`.
* `{{EXIT_NANO}}` — авто-сохранение и выход из `nano`.
* `{{EXIT_VIM}}` — авто-сохранение и выход из `vim`.
* `{{MC_DEL_LINE}}` / `{{NANO_DEL_LINE}}` — удаление текущей строки.
* `{{DOWN}}`, `{{TAB}}` — навигация.
