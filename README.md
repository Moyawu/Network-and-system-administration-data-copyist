# 🚀 Network and System Administration Data Copyist

**ALT Linux Sysadmin DE Modules** — это расширение (Manifest V3), созданное для быстрого доступа к инструкциям и скриптам на страницах wiki ALT Linux, а также для **незаметного ввода конфигураций в консолях Proxmox (noVNC / xterm.js)** при сдаче Демонстрационного экзамена (ДЭ).

## ✨ Главные фичи v1.10-beta (The Ultimate Hackerman Update)

* **⌨️ Изолированный Hackerman Mode (Alt + 6):** Нажмите `Alt + 6` в окне консоли (экран моргнет фиолетовым). Теперь расширение берет клавиатуру под полный контроль: любые хоткеи и случайные нажатия блокируются, а в консоль идеально вводится заскриптованный текст. Консоль теперь корректно «съедает» все спецсимволы (`<`, `>`, `|`, `"`). Для паузы/выхода нажмите `ESC`.
* **🔄 Система Фаз (Alt + 7):** Разделение скриптов на логические этапы.
  * *Фаза 1 (по умолчанию):* Копируется код только для конкретной машины (заголовки `## HQ-RTR`).
  * *Фаза 2 (Финальная):* По нажатию `Alt + 7` копируются только общие куски кода, где в заголовке указано несколько машин (например, `## BR-RTR и HQ-RTR`).
* **🧠 Умные тайминги (Smart Wait):** При вводе команд установки пакетов (`apt-get`, `epm`) ввод блокируется на **5 секунд**. Для редакторов (`mcedit`, `nano`) — на **1.5 секунды**, для перезапуска сервисов — на **2 секунды**. 
* **🪄 Макросы выхода из редакторов:** Вы можете прописать специальные теги в конце текста в ваших `.md` файлах. Расширение автоматически нажмет правильную комбинацию клавиш для сохранения и выхода!
  * `{{EXIT_MCEDIT}}` — (эмулирует F2, Enter, F10)
  * `{{EXIT_NANO}}` — (эмулирует Ctrl+O, Enter, Ctrl+X)
  * `{{EXIT_VIM}}` — (эмулирует Esc, :wq, Enter)
* **📡 Proxmox Cross-Sync:** Расширение работает поверх интерфейса Proxmox. Клик по имени виртуальной машины в дереве автоматически загружает нужные команды для этой машины.

## 🎮 Горячие клавиши и Управление

| Комбинация / Кнопка | Действие | Индикация (рамка 1px) |
| :--- | :--- | :--- |
| `Alt` + `1` | Сделать активным **Модуль 1** (Сеть, ISP, RTR) | ⬜ Светло-серая |
| `Alt` + `2` | Сделать активным **Модуль 2** (RAID, NFS, Samba) | ⬛ Темно-серая |
| `Alt` + `3` | **Smart Paste:** парсинг задания из буфера ОС | 🟩 Зеленая |
| `Alt` + `4` | **Авто-IP:** генерация случайных подсетей | 🟦 Синяя |
| `Alt` + `5` | **Сброс:** откат к стандартному конфигу | 🟧 Оранжевая |
| `Alt` + `6` | **Режим Хакера:** Старт / Продолжить | 🟪 Фиолетовая |
| `Alt` + `7` | **Переключение Фазы:** Основная ↔ Финальная | ⬜ Белая |
| `Escape` (в режиме Hackerman) | **Пауза:** Прервать набор текста | 🟥 Красная |
| `Escape` (вне режима) | **Kill-switch / Hide:** Скрыть модули | - |
