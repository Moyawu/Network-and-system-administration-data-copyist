# 🚀 Network and System Administration Data Copyist

**ALT Linux Sysadmin DE Modules** — это расширение (Manifest V3), созданное для быстрого доступа к инструкциям и скриптам прямо на страницах wiki ALT Linux с акцентом на максимальную скрытность и безопасность.

## ✨ Главные фичи v1.3

* **🥷 Улучшенный Paranoia Mode:** Блоки с кодом теперь идеально мимикрируют под таблицы MediaWiki.
* **🛡️ Kill-switch (Самоуничтожение):** Тройное нажатие `Esc` полностью удаляет расширение со страницы (скрипты, стили и обработчики событий), не оставляя следов до следующей перезагрузки.
* **👀 Слежка за фокусом и курсором:** Модули автоматически скрываются при:
    * Смене вкладки или сворачивании окна (`Alt+Tab`).
    * Уводе курсора мыши в верхнюю часть экрана (верхние 10 пикселей).
* **📋 Скрытое копирование:** Никаких лишних кнопок. Клик по блоку кода — и он в буфере обмена (сопровождается коротким зеленым визуальным подтверждением).
* **⚙️ Интерактивная конфигурация:** IP-адреса и домены теперь можно менять прямо в интерфейсе расширения перед копированием команд.

## 🎮 Горячие клавиши

| Комбинация | Действие |
| :--- | :--- |
| `Alt` + `1` | Показать / Скрыть **Модуль 1** (Сеть, ISP, RTR) |
| `Alt` + `2` | Показать / Скрыть **Модуль 2** (RAID, NFS, Samba, Docker) |
| `Escape` (1 раз) | **Panic Button:** Моментально скрыть открытые модули |
| `Escape` (3 раза) | **Kill-switch:** Полное удаление расширения со страницы |
| `Ctrl` + `Shift` + `0` | Дополнительная паник-кнопка скрытия |

## 🛠️ Установка

1. Перейдите в `chrome://extensions/`.
2. Включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку проекта.
4. После внесения изменений в `.md` файлы или код — нажмите кнопку **«Обновить»** (круговая стрелка) на карточке расширения.

## 📂 Структура проекта
* `manifest.json` (v1.3) — настройки и права расширения.
* `content.js` — ядро: логика стелс-режима, хоткеев и инъекции стилей.
* `marked.min.js` — парсер Markdown.
* `modul_1.md` / `modul_2.md` — шаблоны конфигураций.
