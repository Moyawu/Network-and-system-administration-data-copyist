# 🚀 Network and System Administration Data Copyist

**ALT Linux Sysadmin DE Modules** — это расширение (Manifest V3), созданное для быстрого доступа к инструкциям и скриптам прямо на страницах wiki ALT Linux с акцентом на максимальную скрытность, безопасность и автоматизацию при сдаче Демонстрационного экзамена (ДЭ).

## ✨ Главные фичи v1.5 (Ultimate Stealth & Automation)

* **🧠 Авто-калькулятор подсетей (Auto-IP):** Кнопка `🎲 Авто-IP` генерирует абсолютно уникальную, но 100% правильную схему IP-адресов по стандартам RFC1918 под нужные маски. У вас всегда будут разные IP с соседями!
* **🥷 Стелс-перехват из буфера (Smart Paste):** Нажмите `Alt + 3`, и расширение незаметно прочитает скопированный текст из PDF-задания в буфере обмена, само найдет домен, пароли, порты и сети провайдера, и подставит их в код.
* **💾 Железобетонная память:** Все спарсенные и сгенерированные IP-адреса и пароли сохраняются в `LocalStorage`. При случайном закрытии вкладки или перезапуске браузера ничего не пропадет.
* **🔄 Сброс настроек:** Кнопка быстрого отката к эталонным (заводским) настройкам задания.
* **👻 Фантомный код:** По умолчанию блоки с кодом полностью скрыты. Модуль выглядит как обычный конспект.
* **🖱️ Интерактивные заголовки:**
  * **ЛКМ** по заголовку — незаметно копирует скрытый под ним код в буфер обмена (заголовок мигнет зеленым).
  * **ПКМ** по заголовку — показывает/скрывает код для чтения (меню браузера заблокировано).
* **🛡️ Kill-switch (Самоуничтожение):** Тройное нажатие `Esc` полностью выпиливает расширение со страницы, не оставляя следов в коде (DOM).
* **👀 Слежка за фокусом:** Модули автоматически скрываются при `Alt+Tab`, смене вкладки или уводе курсора мыши за верхний край экрана.

## 🎮 Горячие клавиши и Управление

| Комбинация / Кнопка | Действие |
| :--- | :--- |
| `Alt` + `1` | Показать / Скрыть **Модуль 1** (Сеть, ISP, RTR) |
| `Alt` + `2` | Показать / Скрыть **Модуль 2** (RAID, NFS, Samba, Docker) |
| `Alt` + `3` | **Стелс-перехват:** Спарсить домен/пароли/сети из буфера обмена |
| `Escape` (1 раз) | **Panic Button:** Моментально скрыть открытые модули |
| `Escape` (3 раза) | **Kill-switch:** Полное удаление расширения со страницы |
| `Ctrl` + `Shift` + `0` | Дополнительная паник-кнопка скрытия |
| **Кнопка** `📋 Из буфера`| Ручной запуск парсинга скопированного текста задания |
| **Кнопка** `🎲 Авто-IP` | Сгенерировать рандомные правильные IP для VLAN и туннелей |
| **Кнопка** `🔄 Сброс` | Откатить конфиг к стандартному из образца ДЭ |

## 🛠️ Установка

1. Перейдите в `chrome://extensions/`.
2. Включите **«Режим разработчика»** в правом верхнем углу.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку проекта.
4. Разрешите браузеру чтение буфера обмена при первом использовании Стелс-перехвата (`Alt+3`).

## 📂 Структура проекта
* `manifest.json` — настройки и права расширения (версия 1.5).
* `content.js` — ядро: логика стелс-режима, генератор IP, парсер буфера обмена и инъекция стилей.
* `marked.min.js` — парсер Markdown.
* `modul_1.md` / `modul_2.md` — файлы с шаблонами конфигураций и инструкциями.
