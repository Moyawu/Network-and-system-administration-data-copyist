# 🚀 Network and System Administration Data Copyist

**ALT Linux Sysadmin DE Modules** — это расширение (Manifest V3), созданное для быстрого доступа к инструкциям и скриптам на страницах wiki ALT Linux, а также для **незаметного ввода конфигураций в консолях Proxmox (noVNC / xterm.js)** при сдаче Демонстрационного экзамена (ДЭ).

## ✨ Главные фичи v1.9 (The Hackerman Update)

* **⌨️ Hackerman Mode (Alt + 6):** Нажмите `Alt + 6` в окне консоли (экран моргнет фиолетовым). Теперь **любые** нажатия на вашей клавиатуре (включая случайные хоткеи и Alt-сочетания) будут заблокированы, а вместо них в консоль посимвольно начнет вводиться правильный код из буфера! Для паузы/остановки используйте `ESC`. Нажмите `Alt + 6` еще раз, чтобы продолжить с места остановки.
* **🧠 Умные тайминги (Smart Wait):** Если скрипт печатает команду `mcedit`, `nano` или `vi`, он автоматически заблокирует ввод на **1.5 секунды**, ожидая открытия редактора. При вводе команд установки пакетов (`apt-get install`, `epm` и т.д.) ввод блокируется на **5 секунд**, чтобы дать серверу время на скачивание.
* **🪄 Макросы выхода из редакторов:** Вы можете прописать специальные теги в конце текста в ваших файлах `modul_1.md` / `modul_2.md`. Расширение автоматически нажмет правильную комбинацию клавиш для сохранения и выхода! Поддерживаются:
  * `{{EXIT_MCEDIT}}` — (эмулирует F2, Enter, F10)
  * `{{EXIT_NANO}}` — (эмулирует Ctrl+O, Enter, Ctrl+X)
  * `{{EXIT_VIM}}` — (эмулирует Esc, :wq, Enter)
* **📡 Proxmox Integration & Cross-Sync:** Расширение работает поверх интерфейса Proxmox. Кликните левой кнопкой мыши по имени виртуальной машины в дереве, и скрипт автоматически загрузит нужные команды для этой машины.

## 🎮 Горячие клавиши и Управление

| Комбинация / Кнопка | Действие | Индикация (рамка 1px) |
| :--- | :--- | :--- |
| `Alt` + `1` | Сделать активным **Модуль 1** (Сеть, ISP, RTR) | ⬜ Светло-серая |
| `Alt` + `2` | Сделать активным **Модуль 2** (RAID, NFS, Samba) | ⬛ Темно-серая |
| `Alt` + `3` | **Smart Paste:** парсинг задания из буфера ОС | 🟩 Зеленая |
| `Alt` + `4` | **Авто-IP:** генерация случайных подсетей | 🟦 Синяя |
| `Alt` + `5` | **Сброс:** откат к стандартному конфигу | 🟧 Оранжевая |
| `Alt` + `6` | **Режим Хакера:** Старт / Продолжить | 🟪 Фиолетовая |
| `Escape` (в режиме Hackerman) | **Пауза:** Прервать набор текста | 🟥 Красная |
| `Escape` (вне режима) | **Kill-switch / Hide:** Скрыть модули | - |
