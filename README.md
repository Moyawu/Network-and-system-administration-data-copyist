# 🚀 Network and System Administration Data Copyist

**ALT Linux Sysadmin DE Modules** — это расширение (Manifest V3), созданное для быстрого доступа к инструкциям и скриптам на страницах wiki ALT Linux, а также для **незаметного и автоматизированного ввода конфигураций в консолях Proxmox (noVNC / xterm.js)** при сдаче Демонстрационного экзамена (ДЭ).

## ✨ Главные фичи v1.10 (The Ultimate Hackerman Update)

* **⌨️ Изолированный Hackerman Mode (Alt + 6):** Расширение берет клавиатуру под полный контроль. При активации (фиолетовая рамка) любые случайные нажатия и системные хоткеи блокируются, а в консоль посимвольно вводится заскриптованный код.
* **⌨️ Исправление спецсимволов:** Внедрена физическая карта US-раскладки. Теперь символы `<`, `>`, `|`, `"` и другие корректно передаются в консоль `noVNC` без потерь.
* **🔄 Система Фаз (Alt + 7):** Интеллектуальное разделение скриптов.
  * *Фаза 1 (Основная):* Копирует код для конкретно выбранной машины (заголовки типа `## HQ-RTR`).
  * *Фаза 2 (Финальная):* Копирует общие шаги, где задействовано несколько устройств (заголовки типа `## BR-RTR и HQ-RTR`).
* **🧠 Умные тайминги (Smart Wait):** Автоматическая блокировка ввода при выполнении тяжелых операций: 5 секунд для установки пакетов (`apt-get`, `epm`), 1.5 секунды для открытия редакторов (`mcedit`, `nano`) и 2 секунды для перезапуска сервисов.
* **🪄 Макросы выхода из редакторов:** Поддержка автоматического сохранения и выхода из текстовых редакторов через теги в `.md` файлах:
  * `{{EXIT_MCEDIT}}` — эмулирует F2, Enter, F10.
  * `{{EXIT_NANO}}` — эмулирует Ctrl+O, Enter, Ctrl+X.
  * `{{EXIT_VIM}}` — эмулирует Esc, :wq, Enter.
* **📡 Proxmox Integration:** Прямая работа с деревом устройств Proxmox. Клик по имени ВМ автоматически подгружает нужный контекст в буфер «Призрака».

## 🎮 Горячие клавиши и Управление

| Комбинация / Кнопка | Действие | Индикация (рамка 1px) |
| :--- | :--- | :--- |
| `Alt` + `1` / `Alt` + `2` | Выбор активного модуля (1 или 2) | ⬜/⬛ Серая |
| `Alt` + `3` | **Smart Paste:** парсинг из буфера ОС | 🟩 Зеленая |
| `Alt` + `4` | **Авто-IP:** генерация уникальных подсетей | 🟦 Синяя |
| `Alt` + `5` | **Сброс:** откат к дефолтной конфигурации | 🟧 Оранжевая |
| `Alt` + `6` | **Режим Хакера:** Старт / Продолжить | 🟪 Фиолетовая |
| `Alt` + `7` | **Переключение Фазы:** Основная ↔ Финальная | ⬜ Белая |
| `Escape` (в режиме) | **Пауза:** Прервать набор текста | 🟥 Красная |
| `Escape` (вне режима) | Скрыть модули на Wiki / Panic Button | - |

## 🛠️ Установка
1. Перейдите в `chrome://extensions/` и включите **«Режим разработчика»**.
2. Нажмите **«Загрузить распакованное расширение»** и выберите папку проекта.
3. Разрешите чтение буфера обмена.
4. **Важно:** Обновите (`F5`) все вкладки после установки.
