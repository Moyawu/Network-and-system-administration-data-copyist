# 🚀 Network and System Administration Data Copyist

**ALT Linux Sysadmin DE Modules** — это расширение (Manifest V3), созданное для быстрого доступа к инструкциям и скриптам на страницах wiki ALT Linux, а также для **незаметного ввода конфигураций в консолях Proxmox (noVNC / xterm.js)** при сдаче Демонстрационного экзамена (ДЭ).

## ✨ Главные фичи v1.9-beta (The Hackerman Update)

* **⌨️ Hackerman Mode (Умная призрачная печать):** Нажмите `Alt + V` в окне консоли (экран моргнет фиолетовым). Теперь **любые** нажатия на вашей клавиатуре будут заблокированы, а вместо них в консоль посимвольно начнет вводиться правильный код из буфера! Вы просто хаотично бьете по клавишам, а на экране без ошибок набирается нужный скрипт со скоростью живого человека (с учетом задержек и пауз на `Enter`).
* **📡 Proxmox Integration & Cross-Sync:** Расширение работает поверх интерфейса Proxmox. Кликните левой кнопкой мыши по имени виртуальной машины в дереве (например, `101 (ISP)` — текст моргнет зеленым), и скрипт автоматически загрузит нужные команды для этой машины в память Призрачной печати. Общая память (`chrome.storage.local`) мгновенно синхронизирует IP-адреса и скопированный код между вкладкой Wiki и окнами Proxmox.
* **🧠 Авто-IP калькулятор:** Кнопка `🎲 Авто-IP` генерирует уникальные, 100% правильные сети по стандартам RFC1918. Никаких одинаковых IP с соседями!
* **🥷 Ультра-стелс:** Визуальные индикаторы (моргание экрана при переключении режимов) сведены к полупрозрачным рамкам толщиной всего 1 пиксель. Ни одна программа записи экрана (OBS) или проверяющий эксперт этого не заметят.
* **🪄 Smart Paste:** Нажмите `Alt + 3`, чтобы скрипт сам нашел в скопированном PDF-задании домены, пароли и сети провайдера.

## 🎮 Горячие клавиши и Управление

| Комбинация / Кнопка | Действие | Индикация (рамка 1px) |
| :--- | :--- | :--- |
| `Alt` + `1` | Сделать активным **Модуль 1** (Сеть, ISP, RTR) | ⬜ Светло-серая |
| `Alt` + `2` | Сделать активным **Модуль 2** (RAID, NFS, Samba) | ⬛ Темно-серая |
| `Alt` + `3` | **Smart Paste:** парсинг задания из буфера ОС | 🟩 Зеленая |
| `Alt` + `4` | **Авто-IP:** генерация случайных подсетей | 🟦 Синяя |
| `Alt` + `5` | **Сброс:** откат к стандартному конфигу | 🟧 Оранжевая |
| `Alt` + `V` | **Режим Хакера:** активация перехвата клавиатуры | 🟪 Фиолетовая |
| `Escape` (в режиме Hackerman) | Экстренно прервать набор текста | 🟥 Красная |
| `Escape` (1 раз) | **Panic Button:** скрыть открытые модули Wiki | - |
| `Escape` (3 раза) | **Kill-switch:** выпилить расширение со страницы | - |

## 🛠️ Установка

1. Перейдите в `chrome://extensions/`.
2. Включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку проекта.
4. Разрешите браузеру чтение буфера обмена при запросе.
5. **Важно:** Обновите (`F5`) открытые вкладки Proxmox и Wiki после установки новой версии.
