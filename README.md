# 🚀 ALT Linux Sysadmin DE Modules

**ALT Linux Sysadmin DE Modules** — это мощное stealth-расширение (Manifest V3) для браузеров на базе Chromium. Создано для быстрого доступа к инструкциям и **незаметного, автоматизированного ввода конфигураций в консолях Proxmox (noVNC / xterm.js)** при сдаче Демонстрационного экзамена (ДЭ) по системному администрированию.

## 🔥 Что нового в версии 1.12 (The Smart Update)

* **🧩 Модульная архитектура:** Код разделен на независимые логические слои (`state.js`, `keyboard.js`, `parser.js`, `ui.js`, `content.js`), что делает работу расширения молниеносной, а поддержку кода — простой.
* **🧠 Умный поиск (Smart Fetch):** Больше не нужно вручную переключать модули! Просто кликните по имени ВМ в дереве Proxmox (например, `101 (isp)`), и расширение **само найдет** нужный код во всех файлах/фазах, автоматически переключит интерфейс и подсветит рамку нужным цветом.
* **🎯 Keysym Injection (Бронебойный ввод):** Физическая раскладка клавиатуры больше не имеет значения. Спецсимволы (вроде `|`, `>`, `{`) отправляются напрямую в noVNC как чистые коды символов. Никаких случайных слэшей вместо труб!
* **📋 Динамический парсинг КОД (Alt + 3):** Скопируйте текст из PDF-файла с заданием, и расширение автоматически вытянет не только пароли и домены, но и **UID, уровни RAID, VLAN ID и подсети**.
* **🛡️ Защита от мисскликов:** Игнорирование кликов по интерфейсным панелям Proxmox (ExtJS) — скрипт срабатывает только при точном клике по имени машины.

## ✨ Главные фичи

* **⌨️ Изолированный Hackerman Mode (Alt + 6):** Расширение берет клавиатуру под полный контроль. При активации (фиолетовая рамка) любые случайные нажатия и системные хоткеи блокируются, а в консоль посимвольно вводится заскриптованный код со скоростью профессионального слепого набора.
* **🔄 Двухфазная система (Alt + 7):** Интеллектуальное разделение скриптов внутри Markdown файлов:
  * *Фаза 1 (Основная):* Код для конкретной машины (заголовки типа `## HQ-RTR`).
  * *Фаза 2 (Финальная):* Общие шаги для нескольких устройств (заголовки типа `## BR-RTR и HQ-RTR`).
* **🧠 Умные тайминги (Smart Wait):** Автоматическая блокировка ввода при выполнении тяжелых операций: 5 секунд для установки пакетов (`apt-get`), 1.5 секунды для редакторов (`mcedit`) и 2 секунды для перезапуска сервисов.
* **🪄 Макросы управления:** Поддержка служебных команд прямо в `.md` файлах:
  * `{{EXIT_MCEDIT}}` / `{{EXIT_NANO}}` / `{{EXIT_VIM}}` — авто-сохранение и выход.
  * `{{MC_DEL_LINE}}` / `{{NANO_DEL_LINE}}` — удаление строк.
  * `{{DOWN}}`, `{{TAB}}` — навигация по конфигурационным файлам без мыши.

## 🎮 Горячие клавиши и Управление

Системные хоткеи имеют наивысший приоритет и работают всегда, даже если запущен скрипт ввода.

| Комбинация / Кнопка | Действие | Индикация (рамка) |
| :--- | :--- | :--- |
| `Alt` + `1` / `Alt` + `2` | Принудительный выбор активного модуля (1 или 2) | ⬜/⬛ Серая |
| `Alt` + `3` | **Smart Paste:** парсинг вводных данных из буфера обмена (PDF КОД) | 🟩 Зеленая |
| `Alt` + `4` | **Авто-IP:** генерация уникальных "серых" подсетей | 🟦 Синяя |
| `Alt` + `5` | **Сброс:** откат к дефолтной конфигурации параметров | 🟧 Оранжевая |
| `Alt` + `6` | **Режим Хакера:** Старт / Продолжить печать из «Призрачного буфера» | 🟪 Фиолетовая |
| `Alt` + `7` | **Смена Фазы:** Переключение между Фазой 1 и Фазой 2 | ⬜ Белая |
| `Ctrl`+`Shift`+`0` или `Esc` | **Кнопка Паники:** Моментально скрыть интерфейс расширения | — |

## 🛠️ Установка и Использование

1. Скачайте/склонируйте репозиторий на локальную машину.
2. Откройте браузер и перейдите по адресу `chrome://extensions/` (или `edge://extensions/`).
3. Включите **«Режим разработчика»** (Developer mode) в правом верхнем углу.
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку с исходным кодом.
5. Зайдите в интерфейс Proxmox. Кликните по любой машине (например, `ISP`) — расширение подхватит код из `.md` файлов.
6. Откройте консоль (noVNC), переведите фокус в черное окно и нажмите `Alt + 6`.

> **Примечание:** Шаблоны настроек хранятся в файлах `modul_1.md` и `modul_2.md`. Вы можете редактировать их под свои нужды, используя Markdown и синтаксис переменных `{{ПЕРЕМЕННАЯ}}`.
